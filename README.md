# IPL Cricket SQL Analysis

## 📌 Project Overview

This project analyzes Indian Premier League (IPL) cricket data using SQL.

The analysis focuses on matches, teams, players, batting performance, bowling performance, and match results to extract meaningful insights from IPL data.

## 📂 Dataset

The project uses two datasets:

- `matches.csv` – Contains match-level information such as teams, venue, toss, winner, and result.
- `deliveries.csv` – Contains ball-by-ball information including batsman, bowler, runs, wickets, and extras.

## 🔍 SQL Analysis

The project includes SQL queries to analyze:

- Team performance

- Player performance

- Bowling statistics

- Wickets taken
- Match outcomes

## 🚀 How to Run

1. Download or clone this repository.
2. Import `matches.csv` into MySQL.
3. Import `deliveries.csv` into MySQL.
4. Create the required tables.
5. Run the queries in `IPL_Analysis.sql`.
